# Personal Wiki

Welcome to my personal wiki. Two main sections:

- [Notes & Learning](notes-learning/README.md) — book notes, course notes, things I'm learning
- [Projects & How-Tos](projects-howtos/README.md) — project docs, setup guides, recipes and procedures

## How this is organized

Each section has its own folder with a `README.md` index page. To add a new page:

1. Create a new `.md` file inside the relevant folder
2. Link it from that folder's `README.md`
3. Commit and push

## Page template

```md
# Title

*Tags: tag1, tag2*
*Last updated: YYYY-MM-DD*

## Summary

One or two sentences on what this is.

## Details

...

## Links / references

- [source](url)
```
